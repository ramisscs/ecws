# ECWS — Electronic Correspondence & Workflow System

نظام المراسلات الإلكترونية وسير العمل لجمعية صباح السالم التعاونية

## المتطلبات

- PHP 8.2+
- MySQL 8.0+ أو MariaDB 10.5+
- Composer 2.6+
- Node.js 18+

## التثبيت

### 1. تثبيت الاعتماديات

```bash
composer install --no-dev --optimize-autoloader
npm install && npm run build
```

### 2. إعداد البيئة

```bash
cp .env.example .env
php artisan key:generate
```

ثم عدل ملف `.env` ببيانات قاعدة البيانات وإعدادات البريد.

### 3. إنشاء قاعدة البيانات

```bash
php artisan migrate --force
php artisan db:seed --force
```

### 4. إنشاء رابط التخزين

```bash
php artisan storage:link
```

### 5. تشغيل

```bash
php artisan serve
```

## نظام تسجيل الدخول

### تسجيل الدخول بالرقم الوظيفي

يتم تسجيل الدخول بالرقم الوظيفي وكلمة المرور (ليس بالبريد الإلكتروني).

### بيانات الدخول الافتراضية

| الدور | الرقم الوظيفي | كلمة المرور الافتراضية |
|-------|--------------|---------------------|
| المدير العام | `2048` | `ECWS@2026` |
| رئيس الموارد البشرية | `3001` | `ECWS@2026` |
| رئيس المالية | `3002` | `ECWS@2026` |
| رئيس الشؤون القانونية | `3003` | `ECWS@2026` |
| رئيس خدمات الأعضاء | `3004` | `ECWS@2026` |
| رئيس التسويق | `3005` | `ECWS@2026` |
| رئيس تقنية المعلومات | `3006` | `ECWS@2026` |
| رئيس المشتريات | `3007` | `ECWS@2026` |
| موظف | `4001` | `ECWS@2026` |

### أول دخول — تغيير كلمة المرور

عند أول دخول لأي موظف، يُطلب منه **إجبارياً** تغيير كلمة المرور الافتراضية قبل الوصول للنظام.

## إدارة المستخدمين (مدير النظام فقط)

فقط مدير النظام يمكنه:

- **إنشاء حسابات جديدة** مع تحديد:
  - الرقم الوظيفي
  - الاسم الكامل
  - الرقم المدني
  - المسمى الوظيفي
  - القسم
  - الدور الوظيفي
  - كلمة المرور الافتراضية
- **تفعيل/تعطيل** الحسابات
- **إعادة تعيين كلمة المرور** لأي موظف
- **تعديل البيانات الشخصية**

## المميزات الرئيسية

- نظام ترقيم موحد (SSCS-PREFIX)
- 6 أنواع معاملات (وارد، صادر، داخلي، تعميم، مذكرة، قرار)
- محرك سير عمل كامل مع سجل زمني
- أمان متعدد الطبقات (CSRF, XSS, SQL Injection, RBAC, 2FA)
- معاملات سرية مشفرة
- ذكاء اصطناعي (تلخيص، اقتراح رد، إعادة صياغة)
- أرشفة ذكية وبحث متعدد المعايير
- إشعارات (داخلية، بريد، واتساب)
- واجهة عربية RTL بالكامل
- دعم الوضع الداكن
- تسجيل دخول بالرقم الوظيفي
- تغيير إجباري لكلمة المرور عند أول دخول
- إدارة المستخدمين حصرياً من قبل مدير النظام
